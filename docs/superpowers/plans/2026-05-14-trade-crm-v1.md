# Trade CRM V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a runnable V1 foreign-trade CRM workspace with customer, opportunity, follow-up, communication, order, and insight modules.

**Architecture:** Keep the first version dependency-free and browser-native so it can run inside the current repository without package installation. Put reusable CRM behavior in `trade-crm/src/crm-core.mjs`, sample business data in `trade-crm/src/sample-data.mjs`, and UI composition in `trade-crm/app.js`.

**Tech Stack:** HTML, CSS, browser ES modules, Node.js built-in test runner.
