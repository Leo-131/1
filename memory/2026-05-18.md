5. **曾经有效的方式**：进入对方主页 → 点击"发消息"按钮 → 在 DM 弹窗 textbox 打字发送。之前成功发过 7 条 DM。

- IG 的 DM 交互在 CfT 浏览器中存在严重问题
- 可尝试：`/direct/new/` 搜索 → 选中 → **直接观察 URL 或 network 请求**，看是否有实际 API 调用
- 或尝试：直接进入目标主页 → 点击发消息（MW/KTP 已失败）

## Outreach Dashboard v17 升级（~17:30-18:00）

### 新增功能（写入 outreach_dashboard_v16.html，文件名未改但内容已是v17）
1. **Automation Control Console** — 顶部自动化控制面板
